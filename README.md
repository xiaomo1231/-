# 律动工坊 · GrooveLab

流行 / 摇滚乐理训练网站：先练耳朵、节奏和音准，再学和声、歌曲结构与编曲，最终独立写出自己的歌。

- 纯前端，数据只保存在本机浏览器（IndexedDB）。
- 推荐电脑版 Chrome，佩戴耳机。
- 完整产品方案见 `方案.md`，开发约定见 `AGENTS.md`。

## 运行

需要 Node.js 20 及以上。最简单的方式是双击 **Start.bat**：首次运行会安装依赖，源码有变化时自动构建，然后在 http://localhost:5174 打开。这是可安装、可离线使用的正式版本（Chrome 地址栏右侧的安装图标可以把它装成应用）。

开发时用：

```bash
npm install
npm run dev
```

端口固定为 5174，开发版和正式版共用同一份数据。换端口会看到一个空的数据库。

## 0.21.0（跟唱后期升级）

- **更多效果**：噪声门、动态 EQ、第二级压缩、并行压缩、饱和（磁带 / 电子管 / 失真）、调制（合唱 / 镶边 / 移相 / 加倍）；齿音消除改成真正的动态去齿音；混响可选房间 / 板式 / 大厅并能单独切低频和高频；延迟可乒乓、可切高频。
- **效果顺序可以调**：人声经过哪些效果、先后顺序一目了然，可以前后移动。
- **人声预处理**：逐句音量平衡（还能逐句微调），以及实验性的音高修正（往最近的半音或调内音拉）。
- **伴奏**：人声出现时伴奏自动让一点（侧链），伴奏中频给人声留位置；分轨伴奏可以分别调鼓、贝斯、吉他……的音量。
- **母线**：多段压缩、立体声宽度、限幅上限；导出时可以一键到目标响度（−16 / −14 / −11 / −9 LUFS），并用真峰值限幅保护。
- **看得见声音**：实时频谱（标出伴奏盖住人声的地方）、瞬时响度、左右相关性。
- **智能建议**：本地分析你的人声和伴奏，告诉你最值得调什么、一键应用；配置了 AI 的话还能请 AI 老师点评（只给建议，不改设置）。
- **预设**：新增抒情、民谣、说唱、R&B、Lo-fi、KTV；可以存自己的预设（所有歌通用）和这首歌的快照（A/B 来回比）。
- **导出 MP3**（128–320 kbps）。每个效果下面都有对应的后期课堂链接。

## 0.20.0（后期课堂）

- **侧边栏新增「后期课堂」**：七个单元共 46 课——基础（电平、LUFS、余量、公平比较、听感词汇）、均衡、动态（压缩、并行压缩、噪声门、去齿音、侧链）、空间（混响、延迟、调制、声像）、人声专项（逐句音量平衡、加倍、音高修正）、染色（饱和、失真、激励）、混音与母带（多段压缩、M/S 宽度、响度标准、真峰值、导出）。
- 每课：图解 + 讲解 + 要点；大多数课有「听一听」A/B 对比（自动把音量对齐）和「动手做」任务（边听边调，点「检查」自动判断，给出具体差多少）。
- **用你自己的声音上课**：录 20 秒，或直接用跟唱里的录音；没录时用合成的示范人声。伴奏素材是网站自己生成的鼓、贝斯和钢琴，不含任何受版权保护的歌曲。
- **听辨练习**：EQ 频率、提升还是衰减、低切、压缩多少、混响长短、延迟时值、声像、失真、响度差、立体声宽度，十种练习各四级，答对自动升级；不进每日训练。
- **修复**：浏览器分轨中途进程崩溃（常见于内存不够）时，会自动改用处理器、再减少并行路数重试，不再只显示「分轨进程出错」。

## 0.16.2

- **按歌词分句**：粘贴歌词后，网站会根据原唱的音高和停顿自动把每一行对到时间上，先给你看「自动对齐结果」，确认后跟唱就按歌词一行一句；句中换气不再把一句切成两半。导入 LRC 或用打拍对齐也会按歌词分句。

## 0.16.0（跟唱 2.0）

## 0.15.0（一键自动分轨）

- **只有原曲也能用**：在谱子的「原曲伴奏」或「跟唱」里上传原曲，点「自动分轨」，就会分出人声、鼓、贝斯、吉他、钢琴、其它几轨，直接用来练。
- **本机加速**（推荐）：运行一次 `helper\install.bat`，之后用 Start.bat 启动网站时会自动开启本机分轨助手，用 UVR 的引擎和最好的人声模型在显卡上分轨，一首歌通常几十秒。说明见 `helper/README.md`。
- **不装也行**：没有本机助手时在浏览器里分轨（第一次下载约 285 MB 模型，有显卡加速时一首歌几分钟）。

## 0.13.0（原曲伴奏）

## 0.11.0（我的谱子 · Guitar Pro）

- **侧边栏新增「我的谱子」**：只放你自己导入的谱子，按演唱者分组；同一演唱者的同名谱子合成一首，用下拉框切换版本。可以搜索、排序、编辑歌名 / 演唱者 / 版本名 / 标签。
- **直接导入 Guitar Pro**（.gp3 / .gp4 / .gp5 / .gpx / .gp），也支持 MusicXML、MIDI、粘贴和弦谱 / 六线谱，可以拖放文件。
- **按原谱看和听**：五线谱 + 六线谱、多音轨切换、光标跟随播放、变速、循环选段、预备拍、节拍器、每轨静音 / 独奏，一键“跟伴奏弹”。
- **选一段练**：按原谱指法弹旋律或扫弦，用吉他线 / 麦克风判定；调弦不同（如 Drop D）会提醒并可一键切换。记录每段最好成绩。
- 第三方组件：alphaTab（MPL-2.0）、Bravura 字体（SIL OFL）、Sonivox 音色库（Apache-2.0），许可文件在 `public/alphatab/`。

- **作品点评与版本历史**：作曲台新增“点评”页，规则检查和 AI 点评都会记录下来；每次保存留一个版本，可以回放、恢复。
- **毕业项目**：学完阶段 5 后开放，一首 2–3 分钟、4–6 个声部的完整作品，按动机、和声、结构、编曲、点评、修改、导出七步完成。
- **离线可用**：可以安装成应用，断网时训练、课程、作曲和导出都能用。
- **数据导入**：设置页可以从备份恢复，导出文件现在包含课程进度和全部作品。
- **修复**：吉他音色连续播放时偶尔报错停播的问题。

## 0.4.0（P4）

- **多轨编曲**：键盘、吉他、贝斯、鼓、主旋律五轨，每轨音量、声像、静音、独奏、音色；段落（主歌、副歌等）带能量和移调；流行、摇滚、朋克、轻 R&B 风格模板；任何一轨都能转为手写。
- **编曲检查**：声部数量、贝斯与底鼓是否锁定、音域、低频发闷、音区打架、主副歌对比。
- **进阶和声**：七和弦、挂留、加九、强力和弦、斜线和弦，借用和弦与副属和弦，段落转调。
- **导出**：MIDI、MusicXML、WAV，全部在浏览器里生成。
- **音色**：按乐器区分的合成音色，钢琴为随站打包的 Salamander 采样（Alexander Holm，CC-BY 3.0）。
- **吉他**：Drop D、全弦降半音、变调夹，和弦图显示实际要按的指型。
- **课程**：阶段 4「进阶和声」10 课、阶段 5「编曲」12 课，课程全部上线。

## 0.3.0（P3）

- **三种记谱**：同一份音乐可在五线谱、简谱、六线谱 / 四线谱之间切换（阶段 2 起开放简谱和吉他谱）。
- **作曲工作台**：钢琴卷帘写旋律、罗马数字配和弦、填歌词，播放时自动生成钢琴、贝斯、鼓伴奏。
- **规则检查**：调性、和弦音与非和弦音、音域、大跳、高点、终止式、平行五八度等，实时提示。
- **课程**：新增阶段 2「和声基础」和阶段 3「旋律与歌曲结构」各 10 课，微创作升级为配和弦和写歌。

## 0.2.0（P2）

- **入门分级测试**：8 段自适应（音高、跟拍、识谱、音程、和弦、级数、乐理、音准），给出起步阶段和各模块起始级别。
- **训练营 23 个模块**：听辨 9 个（含和声进行、低音线、旋律听写、节奏听写）、节奏 3 个、唱歌 7 个、五线谱识谱、乐理知识、主乐器与第二乐器任务。
- **麦克风音准**：音域标定、实时音准表，自由唱和跟拍唱两种评分方式。声音只在本机分析，不录音、不上传。
- **乐器**：吉他 / 贝斯指板与和弦图、调音器，乐器任务用麦克风检测你弹的音。
- **课程**：阶段 0「节奏与声音」8 课、阶段 1「音高系统」10 课；每课有课内练习和一段微创作，作品自动进作品集。
- **复习与激励**：间隔重复、每日训练（按弱项和到期复习排课）、经验值与段位、连续天数、徽章、挑战模式、技能地图。

唱歌和乐器功能需要麦克风，请在电脑版 Chrome 里打开，并在弹窗中允许使用麦克风。
