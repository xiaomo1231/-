# 律动工坊 · GrooveLab

流行 / 摇滚乐理训练网站：先练耳朵、节奏和音准，再学和声、歌曲结构与编曲，最终独立写出自己的歌。

- 纯前端，数据只保存在本机浏览器（IndexedDB）。
- 推荐电脑版 Chrome，佩戴耳机。
- 完整产品方案见 `方案.md`，开发约定见 `AGENTS.md`。

## 运行

需要 Node.js 20 及以上。最简单的方式是双击 **Start.bat**：首次运行会安装依赖，源码有变化时自动构建，然后在 http://localhost:5174 打开。这是可安装、可离线使用的正式版本（Chrome 地址栏右侧的安装图标可以把它装成应用）。

开发时用：

```bash
npm install
npm run dev
```

端口固定为 5174，开发版和正式版共用同一份数据。换端口会看到一个空的数据库。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `npm run dev` | 开发服务器（端口 5174） |
| `npm run build` | 类型检查 + 生产构建 |
| `npm run typecheck` | TypeScript 检查 |
| `npm run lint` | ESLint |
| `npm test` | Vitest 单元测试 |
| `npm run app` | 用 Electron 打开应用版（先 `npm run build`；`GROOVELAB_DEV_URL=http://localhost:5174` 可改为加载开发服务器） |
| `npm run package` | 打包应用版（免安装）→ `release/律动工坊-<版本>-win-x64.zip` |

## 0.28.0

- **新音色**：后期的压缩、第二级压缩、并行压缩、齿音消除、饱和和混响换成移植自 [Airwindows](https://github.com/airwindows/airwindows)（Chris Johnson，MIT 许可）的效果器：Pressure4 / ButterComp2（压缩）、DeBess（齿音）、ToTape6 / Tube2 / ADClip8（磁带 / 电子管 / 硬削波）、kPlateD / Verbity2 / Galactic3（板式 / 房间 / 大厅混响）。旋钮不变，按测量把各效果的响度对齐到经典版，混响的衰减时间按实测对上。后期工作台可以在「新音色 / 经典」之间切换对比；以前保存的混音保持经典，预设、自动后期默认新音色。
- **预设重调**：摇滚不再刺耳（临场感移到 2.5 kHz、不额外提亮高频、齿音压得更多、电子管更柔和、加一点回声）；电台改成真正的窄频带（约 400 Hz–3.5 kHz）；流行等预设加了轻微的第二级压缩和磁带温暖感；新音色下各预设的响度基本一致，切换预设不会忽大忽小。

## 0.27.0

- **原唱音高线不再在没人声的地方出灰条**：以前用的是变声软件的宽松门槛，分轨后人声轨里残留的乐器、和声、混响尾巴也被当成人声（四首测试歌平均约 11% 的时长是误报）。现在要求置信度 0.5 以上、并且人声轨在那一刻离它最响的歌声不超过 30 dB：误报降到约 2%，真正唱的部分保留约 96%（以更强的 BS-RoFormer 分离结果作参考统计）。已导入的歌第一次打开时会自动重新分析一次。
- **唱完一句用录音重新分析**：评分和"你唱的线"改用 RMVPE 对这句录音的分析结果（比唱的时候的实时线稳），应用里才有，失败时退回实时结果。
- 同一个音唱好几个字时，按字与字之间的音量下陷切成几个音符。
- 实时线：单帧跳八度会被拉回来。
- 管理员模式：音高图下方显示原唱音高用哪个模型、有声比例、音符数和门槛，方便反馈问题。

## 0.26.7

- **修复：「一口气唱完」/「整首重新开始」录的整首错位**（开头是录音的最后几秒，后面只剩伴奏）。歌曲位置和录音时钟的对照表只留最近约一分钟，整首唱完后找开头时只能从两个紧挨的点往回外推几分钟，误差放大到好几秒。现在每 0.25 秒记一次、整首都留着，超出范围时用首尾两点推算。

## 0.26.6

- **「拼最好的几句」不再上句没完下句就进来**：以前每句的录音整段叠上去（带着句前预备段和句后尾巴），相邻两句会叠在一起——尤其录下一句时预备段里还唱着上一句的尾字。现在先找出每段录音里真正属于这一句的歌声（预备段里上一句的尾字、尾巴里下一句的开头都不算），句与句之间在最安静的地方切开；两句确实连着唱的地方用 80 毫秒交叉淡化。

## 0.24.0

- **原唱音高线换成 RMVPE**：专门从带伴奏残留、混响的人声里提取音高的模型（翻唱变声类工具常用），解决"原唱明明在唱却没识别出音高"。应用里用处理器全部核心计算，一首 4 分钟的歌约 5 秒。已经导入的歌第一次打开时会自动重新分析一次。

- 模型由 `scripts/make-pitch-models.py` 生成到 `public/models/`（RMVPE：代码 Apache-2.0，权重来自 RVC 项目，MIT；SwiftF0：MIT），不进 Git，随应用包分发。
